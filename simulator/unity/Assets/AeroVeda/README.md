# AeroVeda Unity modules

This directory contains the intended simulator architecture for the Unity project.

The structure is organized by system responsibility rather than by a generic scripting dump.

## Modules

- Behavior
- Training
- Difficulty
- AAR
- Entities
- Scenarios
- Sensors
- Scoring
- Logging
- UI
- ScriptableObjects
- Tests

These folders are the target structure for future implementation and should be used as the canonical layout for simulator code.
